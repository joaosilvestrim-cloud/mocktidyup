# TidyUp! ERP — Mockup

Mockup navegável e funcional do ERP (Operating Hub) da **TidyUp! Professional Cleaning Services** (Midland, TX).

Arquivo único, sem dependências de build. Abra `index.html` no navegador.

## Conteúdo

- **`index.html`** — aplicação ERP completa (mesmo que `TidyUp-ERP-app-mockup.html`)
- **`TidyUp-ERP-app-mockup.html`** — cópia do app
- **`TidyUp-ERP-Modules-mockup.html`** — pôster de visão geral dos 12 módulos

## Fluxo

1. **Login** → qualquer credencial entra
2. **Seletor de módulos** — tela cheia, 12 módulos agrupados por camada (Operations, Customers, People, Finance), com fase do roadmap e prioridade
3. **Módulo** — cada módulo com sua tela; sidebar navega, "All Modules" volta ao seletor, "Log out" volta ao login

## Funcionalidades

- Login com validação
- Busca global que filtra a tabela da tela ativa
- Botões New/Add/Create abrem modal com formulário; salvar mostra toast
- Sino de notificações com dropdown
- Filtros clicáveis e linhas de tabela interativas
- Sidebar recolhível com ícones por módulo

## Marca

Paleta oficial: navy `#01475D`, ciano `#02CDFF`, fundo claro. Wordmark recriado em SVG (Tidy + up + vassoura).

> Dados são fictícios (mock). Nenhuma ação persiste — é um protótipo visual.
